
32-bit word width
Each RAM address selects one 32-bit word.

opcode      0-[31:24]

instruction formats:
* operands are (index-after-opcode)-[bitrange]

A
    (none)
B
    operand_a   0-[23:16]
    operand_b   0-[15:08]
    operand_c   0-[07:00]
C
    word_a      1-[31:0]
    word_b      2-[31:0]
D   
    register    0-[23:16]
    word_a      1-[31:0]
E 
    reg_a       0-[23:16]
    reg_b       0-[15:08]


opcode      instruction     format          operands
0           halt            A               -
1           store_imm       C               (ram address, immediate int)
2           load_imm        D               (target-reg, immediate int)
3           store           E               (address reg, value reg)
4           load            E               (target-reg, source addr)
5           add             B               (target-reg, left-reg, right-reg)

add stores the low 32 bits of the two source registers' sum in the target register.
The target register may also be either source register. add occupies one word.

The backend passes structured instructions directly to the assembler.
Assembly text and hexadecimal words are emitted as readable dumps.

The backend emits every function under its own label, with zero-argument main first at RAM word 0.
Each function's entry address is measured in encoded words. Labels occupy no words.
Storage follows all function code, with one 32-bit word per argument, local or temporary slot.
Each function has separate storage. Argument slots are reserved but argument passing is not implemented.
Every return places the result in r0 and halts, so main does not fall through into the other functions.
The runner prints main's result. Calling functions and returning to a caller remain unimplemented.
